# Rick and Morty Explorer

Aplicación web que consulta la [API de Rick and Morty](https://rickandmortyapi.com/) y permite explorar personajes, ubicaciones y episodios.

## Opciones de búsqueda

- **Personajes:** nombre, estado, especie y género.
- **Ubicaciones:** nombre, tipo y dimensión.
- **Episodios:** nombre y código del episodio.
- Resultados paginados y opción para limpiar los filtros.

## Ejecución

Abre `index.html` en un navegador con conexión a internet. La aplicación utiliza `fetch` para consultar la API directamente; no requiere instalación de dependencias.
